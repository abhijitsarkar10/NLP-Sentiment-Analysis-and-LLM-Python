# NLP Sentiment Analysis and LLM using Python

## Project Overview

This project explores Natural Language Processing (NLP), sentiment analysis, and Large Language Models (LLMs) using Python.

The notebook demonstrates different approaches to text processing and sentiment classification, followed by an experiment with an LLM using LangChain and CTransformers.

## Objectives

- Perform basic NLP text processing
- Analyze sentiment from text
- Compare different sentiment analysis approaches
- Explore LLM-based text generation
- Understand practical applications of NLP and LLMs

## Techniques Covered

- TextBlob
- NLTK VADER
- Flair Sentiment Analysis
- LangChain
- CTransformers
- LLM Text Generation

## Technologies

- Python
- Pandas
- NLTK
- TextBlob
- Flair
- LangChain
- CTransformers

## Project Workflow

1. Text preprocessing
2. Text normalization
3. Sentiment analysis using TextBlob
4. Sentiment analysis using VADER
5. Sentiment analysis using Flair
6. LLM setup
7. LLM-based text generation
